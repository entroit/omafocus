# Oma Focus

Oma Focus is a local focus timer for the stock Omarchy bar. It records how a
finished session was divided between focused applications, idle time, and time
that could not be attributed.

> **Development status:** Oma Focus is under active development and is not yet
> ready to install.

Oma Focus stores its data on this computer. It does not collect window titles,
URLs, telemetry, or account data. Session goals are optional and are saved as
plain text, so avoid putting secrets in them.

## Contributing

Open an issue before starting a large change. Keep examples, tests, and
screenshots synthetic; do not commit real session goals or browsing data.
